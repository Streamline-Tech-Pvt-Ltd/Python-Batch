Python Internship Notes Day01:-

1. Definition of Python Programming:-
        Python is a high-level, interpreted, and easy-to-read programming language designed for writing clear and logical code. 
        It is widely used in web development, data science, automation, artificial intelligence, and scripting because of its simple and readable syntax.


    2. Core Python Concepts:-

        1. Simple:-
            Python uses clean and readable syntax that closely resembles plain English, making it easy for beginners to learn.
        2. Dynamic:-
            Python is dynamically typed. You do not need to explicitly declare the data type of a variable. Python determines the type automatically at runtime.
        3. Interpreted:-
            Python programs are executed by an interpreter. Python source code is first compiled into bytecode, which is then executed by the Python Virtual Machine (PVM).
        4. High-Level:-
            Python hides complex hardware-level details such as memory management, allowing programmers to focus mainly on application logic.
        5. General Purpose:-
            Python can be used to develop many types of applications, including websites, automation scripts, desktop applications, data analysis tools, and AI/ML applications.
        6. Object-Oriented Programming (OOP):-
            Python supports object-oriented programming, where programs can be organized around objects that contain data and methods.

3. Difference Between Static Typing and Dynamic Typing:-

| Feature               | Static Typing                                                                           | Dynamic Typing                                                       |
| --------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Type Declaration      | Data types are generally declared or determined before execution. Example: `int x = 5;` | Data types are determined automatically at runtime. Example: `x = 5` |
| Type Checking         | Mainly performed at compile time.                                                       | Mainly performed at runtime.                                         |
| Variable Reassignment | A variable is generally restricted to its declared type.                                | A variable can refer to objects of different types during execution. |
| Error Detection       | Many type errors can be detected before execution.                                      | Type-related errors may appear during execution.                     |
| Code Length           | Usually requires more type-related code.                                                | Usually requires less type-related code.                             |
| Flexibility           | More strict and structured.                                                             | More flexible and concise.                                           |
| Examples              | C, C++, Java, C#                                                                        | Python, JavaScript, Ruby                                             |

4. Indentation in Python:-
    Indentation refers to the spaces or tabs placed at the beginning of a line of code.
    Python uses indentation to define blocks of code instead of using curly braces {}.

    Indentation is commonly used with:
        if and else statements
        for and while loops
        Functions
        Classes
        Exception handling
    
    Example:
        if age >= 18:
        print("You are eligible to vote.")
    
        Here, the print() statement is indented, which indicates that it belongs to the if block.
        Important: Incorrect indentation can result in an IndentationError.

5. Difference Between Compiler and Interpreter:-

| Feature         | Compiler                                                                               | Interpreter                                                                                                              |
| --------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Translation     | Translates the program into machine code or another lower-level form before execution. | Executes the program through an interpreter/runtime environment.                                                         |
| Execution Speed | Generally faster after compilation.                                                    | Traditionally slower because execution involves runtime interpretation, although modern runtimes may optimize execution. |
| Error Reporting | Often reports errors during compilation before the program runs.                       | Errors are commonly reported when the relevant code is executed.                                                         |
| Output          | May generate machine code, object code, or an executable file.                         | Usually does not directly create a standalone executable file.                                                           |
| Memory Usage    | May require additional storage for compiled/object files.                              | Typically does not require a separate executable file for normal execution.                                              |
| Examples        | C, C++, Rust                                                                           | Python, Ruby                                                                                                             |

    Note: Python is commonly called an interpreted language, but CPython actually compiles source code into bytecode before executing it using the Python Virtual Machine (PVM).

10. Difference Between High-Level and Low-Level Language:-

| Feature            | High-Level Language                           | Low-Level Language                              |
| ------------------ | --------------------------------------------- | ----------------------------------------------- |
| Human Readability  | Easy for humans to read and understand.       | Difficult for humans; written in binary/hex.    |
| Hardware Control   | Abstracted away; managed automatically.       | Direct, manual control over CPU and memory.     |
| Execution Speed    | Slower due to extra translation layers.       | Extremely fast as it runs natively on hardware. |

| Memory Management  | Handled automatically by garbage collection.  | Requires manual memory allocation and cleanup.  |
| Primary Examples   | Python, Java, C#.                             | Assembly, Machine Code.                         |

Python Internship Notes: Day 2

1. Programming Paradigms (Types of Programming)

    1. Sequential Programming:-
        Executes code step-by-step from top to bottom using variables, operators, and conditional logic (`if`, `else`).
    2. Functional Programming:-
        Structures code using functions, parameters, arguments, and return values to process data cleanly.
    3. Object-Oriented Programming (OOP):-
        Organizes code using classes, objects, the 4 pillars (Abstraction, Encapsulation, Inheritance, Polymorphism), along with file handling and exception handling.

*/*-*/*-*/*-*/*-*/*

2. Python Keywords

    Definition:-
        Reserved words in Python that have fixed meanings and cannot be used as variable names.
    Checking Keywords:-
        Use `import keyword` followed by `keyword.kwlist` to print all keywords, or `len(keyword.kwlist)` to get the total count.
    Verifying Words:-
        Use `keyword.iskeyword('word')` to check if a specific string is a reserved keyword (returns `True` or `False`).

*/*-*/*-*/*-*/*-*/*

3. Comments in Python:-

    Definition:-
        Explanatory notes in your code that Python ignores during execution.
    Single-Line Comment:-
        Uses the hash symbol (`#`) to annotate a single line.
    Multi-Line Comment:-
        Uses triple single quotes (`'''`) or triple double quotes (`"""`) to write comments spanning multiple lines.

*/*-*/*-*/*-*/*-*/*

4. Variables & Declaration Rules

    Definition:-
        Dynamically typed containers used to store data without needing to explicitly declare the data type.


    Rule 1 (No Starting Numbers):-
        Names must start with a letter or an underscore, never a number (e.g., `user1`, not `1user`).
    Rule 2 (No Special Characters):-
        Only letters, numbers, and underscores (`_`) are allowed; special symbols like `@`, `$`, or `-` are forbidden.
    Rule 3 (No Keywords):-
        Reserved keywords like `if`, `def`, or `finally` cannot be used as variable names.
    Rule 4 (No Spaces):-
        Variable names cannot contain spaces; use underscores instead (e.g., `user_name`).
    Rule 5 (Meaningful Names):-
        Names should clearly describe the data they hold (e.g., `age` instead of `a`).

*/*-*/*-*/*-*/*-*/*

5. Python Data Types

     Primary Data Types
    String (`str`):-
        Text data enclosed in quotes (e.g., `name = 'Anuj Kakad'`).
    Integer (`int`):-
        Whole numbers without decimals (e.g., `number = 123456789`).
    Boolean (`bool`):-
        Logical values representing truth states (`True` or `False`).
    Complex (`complex`):-
        Numbers with a real and imaginary part (e.g., `comp = 2+2j`).

     Collection Data Types
    List:-
        An ordered, mutable (modifiable) sequence of items written in square brackets `[ ]`.
    Tuple:-
        An ordered, immutable (un-changeable) sequence of items written in parentheses `( )`.
    Dictionary:-
        Unordered collection of key-value pairs written in curly braces `{ key: value }`.
    Set:-
        An unordered collection of unique elements written in curly braces `{ }`.
    Frozenset:-
        An immutable (un-changeable) version of a standard set.

Python Internship Notes:- Day 3 - Operators

1. Introduction to Operators:-

    Definition:-
        Symbols used to perform operations on variables and values.
        (e.g., in `a + b`, `a` and `b` are **operands**, and `+` is the **operator**).

*/*-*/*-*/*-*/*-*/*

2. Arithmetic Operators:-
    1. Adition (`+`):- 
        Adds two numbers together 
        (e.g., `10 + 20` outputs `30`).

    2. Subtraction (`-`):-
        Subtracts the right number from the left 
        (e.g., `20 - 10` outputs `10`).
    
    3. Multiplication (`*`):-
        Multiplies two numbers
        (e.g., `10 * 20` outputs `200`).
    
    4. Division (`/`):-
        Divides numbers and always returns a floating-point number
        (e.g., `10 / 20` outputs `0.5`).
    
    5. Modulus (`%`):-
        Returns the remainder left over after division
        (e.g., `10 % 3` outputs `1`).
    
    6. Floor Division (`//`):-
        Divides numbers and chops off decimals to return the lower whole number.
        (e.g., `10 // 3` outputs `3`).
    
    7. Exponentiation (`**`):-
        Raises the base number to a power.
        (e.g., `2 ** 3` outputs `8`).

*/*-*/*-*/*-*/*-*/*

3. Assignment Operators:-

    1. Assign (`=`):-
        Assigns a value to a variable
        (e.g., `x = 20`).
    
    2. Add and Assign (`+=`):-
        Adds a value and assigns result
        (e.g., `x += 10` sets `x` to `30`).
    
    3. Subtract and Assign (`-=`):-
        Subtracts a value and assigns result
        (e.g., `x -= 5` sets `x` to `15`).
    
    4. Multiply and Assign (`*=`):
        Multiplies by a value and assigns result
        (e.g., `x *= 2` sets `x` to `40`).
    
    5. Divide and Assign (`/=`):-
        Divides by a value and assigns result
        (e.g., `x /= 2` sets `x` to `10.0`).
    
    6. Floor Divide and Assign (`//=`):-
        Floor divides and assigns result
        (e.g., `x //= 3` sets `x` to `6`).
    
    7. Modulus and Assign (`%=`):-
        Takes modulus and assigns result
        (e.g., `x %= 3` sets `x` to `2`).
    
    8. Exponentiate and Assign (`**=`):-
        Raises to power and assigns result
        (e.g., `x **= 2` sets `x` to `400`).

*/*-*/*-*/*-*/*-*/*

4. Comparison (Relational) Operators:-

    1. Equal To (`==`):-
        Returns `True` if both values are equal
        (e.g., `20 == 20` outputs `True`).
    
    2. Not Equal To (`!=`):-
        Returns `True` if values are different
        (e.g., `25 != 20` outputs `True`).
    
    3. Greater Than (`>`):-
        Returns `True` if left value is bigger
        (e.g., `25 > 18` outputs `True`).
    
    4. Less Than (`<`):
        Returns `True` if left value is smaller
        (e.g., `15 < 18` outputs `True`).
    
    5. Greater Than or Equal To (`>=`):-
        Returns `True` if left value is bigger or equal
        (e.g., `18 >= 18` outputs `True`).
    
    6. Less Than or Equal To (`<=`):-
        Returns `True` if left value is smaller or equal
        (e.g., `15 <= 18` outputs `True`).

*/*-*/*-*/*-*/*-*/*

5. Logical Operators:-
    
    1.`and`:-
        Returns `True` only if **both** conditions are true
        (e.g., `5 > 2 and 10 > 5` outputs `True`).
    
    2. `or`:-
        Returns `True` if **at least one** condition is true
        (e.g., `15 >= 18 or 10 > 5` outputs `True`).
    
    3. `not`:-
        Reverses the logical state, returning `True` for false conditions and vice versa
        (e.g., `not(10 > 20)` outputs `True`).

*/*-*/*-*/*-*/*-*/*

6. Bitwise Operators:-
    1. Bitwise AND (`&`):-
        Compares bits and sets each bit to `1` only if both corresponding bits are `1`
        (e.g., `5 & 3` outputs `1`).
    
    2. Bitwise OR (`|`):-
        Compares bits and sets each bit to `1` if at least one corresponding bit is `1`
        (e.g., `5 | 3` outputs `7`).
    
    3. Bitwise NOT (`~`):-
        Inverts all bits of a binary number
        (e.g., `~5` outputs `-6`).
    
    4. Bitwise XOR (`^`):-
        Sets each bit to `1` only if one of the corresponding bits is `1`
        (e.g., `5 ^ 3` outputs `6`).

*/*-*/*-*/*-*/*-*/*

7. Membership Operators:-
    
    1. `in`:-
        Returns `True` if a sequence/item is found inside a given object.
        (e.g., `'a' in 'apple'` outputs `True`).
    
    2. `not in`:-
        Returns `True` if a sequence/item is **not** present inside an object.
        (e.g., `10 not in [1, 2, 3]` outputs `True`).
    
    3. Bitwise Left Shift (`<<`):-
        Shifts the bits of a number to the left by a specified number of positions, padding with zeros.
        (e.g., `5 << 1` outputs `10`).
    
    4. Bitwise Right Shift (`>>`):-
        Shifts the bits of a number to the right by a specified number of positions, discarding bits shifted off.
        (e.g., `5 >> 1` outputs `2`).

*/*-*/*-*/*-*/*-*/*

8. Identity Operators:-
    
    1. `is`:-
        Returns `True` if both variables point to the exact same object in computer memory.
        (e.g., `a = 10; b = a; print(a is b)` outputs `True`).
    2. `is not`:-
        Returns `True` if both variables point to different objects in memory.
        (e.g., `x = [1, 2]; y = [1, 2]; print(x is not y)` outputs `True`).
