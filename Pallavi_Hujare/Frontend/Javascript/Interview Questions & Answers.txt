1. What is JavaScript?
Answer:
JavaScript is a high-level, dynamically typed programming language used to make web pages interactive and dynamic.
Example:
let name = "Pallavi";
console.log("Hello " + name);

2. Why is JavaScript used?
Answer:
JavaScript is used to:
Make web pages interactive
Handle user actions like clicks and typing
Validate forms
Manipulate HTML and CSS
Create animations
Communicate with servers using APIs
Build web applications

Example:
document.getElementById("btn").onclick = function() {
    alert("Button clicked!");
};

7. Is JavaScript compiled or interpreted?
Best fresher interview answer:
"Traditionally, JavaScript is described as an interpreted language. However, modern JavaScript engines use JIT (Just-In-Time) compilation to improve performance."
Simple explanation:
JavaScript engines such as Chrome's V8 execute JavaScript using techniques including JIT compilation.
Important: Don't simply say "JavaScript is only interpreted" because modern engines optimize and compile code.

11. What is the difference between var, let, and const?
| Feature                 | `var`          | `let`  | `const` |
| ----------------------- | -------------- | ------ | ------- |
| Reassign                | ✅ Yes        | ✅ Yes  | ❌ No  |
| Redeclare in same scope | ✅ Yes         | ❌ No   | ❌ No |
| Scope                   | Function       | Block  | Block   |
| Modern usage            | Less preferred | Common | Common  |

let age = 20;
age = 21;       // ✅

const pi = 3.14;
pi = 3.15;      // ❌ Error


12. Can we redeclare a let variable?
Answer:
No. A let variable cannot be redeclared in the same scope.
let age = 20;
let age = 21;   // ❌ Error

But it can be reassigned:
let age = 20;
age = 21;       // ✅


13. Can we reassign a const variable?
Answer:
No. A const variable cannot be reassigned after initialization.

const age = 20;
age = 21;       // ❌ Error

Important interview point:
const prevents reassignment of the binding. It does not make objects or arrays completely immutable.

14. What is scope?
Answer:
Scope defines where a variable can be accessed in a program.
Main types:
Global scope
Function scope
Block scope

Example:
let name = "Pallavi";

function test() {
    console.log(name);
}

Here name can be accessed inside the function because it is in an outer/global scope.

15. What is block scope?
Answer:
Block scope means a variable is accessible only inside the block { } where it is declared.
let and const are block-scoped.

if (true) {
    let age = 20;
    console.log(age); // ✅
}
console.log(age);    // ❌ Erro

16. What is function scope?
Answer:
Function scope means a variable declared with var inside a function can be accessed within that function, but not outside it.
function test() {
    var age = 20;
    console.log(age); // ✅
}

console.log(age);    // ❌

18. What are primitive data types?
Answer:
Primitive data types represent single values and are not objects.

The 7 primitive types are:
String
Number
BigInt
Boolean
Undefined
Null
Symbol

 Data Type     | Definition                      | Example             |
| ------------- | ------------------------------- | ------------------- |
| **String**    | Stores text                     | `"Pallavi"`         |
| **Number**    | Stores numbers                  | `20`                |
| **BigInt**    | Stores very large integers      | `12345n`            |
| **Boolean**   | Stores true/false               | `true`              |

29. What is NaN?
Answer:
NaN means Not-a-Number.
It represents an invalid or unsuccessful numeric result.
let result = "hello" / 2;
console.log(result);
Output:
NaN
Interesting point:
typeof NaN
Output:
"number"

30. What is the use of typeof?
Answer:
typeof is an operator used to determine the type of a value.
let age = 20;
console.log(typeof age);

31. Why does typeof null return "object"?
Answer:
This is a historical behavior/legacy bug in JavaScript.
typeof null
Output:
"object"
Although null is actually a primitive value, typeof returns "object" for historical compatibility.

⭐ 38. What is the ternary operator?
Answer:
The ternary operator is a short form of an if...else statement.
Syntax:
condition ? valueIfTrue : valueIfFalse
Example:
let age = 20;
let result = age >= 18 ? "Adult" : "Minor";
console.log(result);
Output:
Adul


39. What is the difference between && and ||?
&& — AND
Returns a truthy result only when both conditions are truthy.
let age = 20;

age > 18 && age < 30
// true
|| — OR
Returns a truthy result when at least one condition is truthy.
let age = 20;
age < 18 || age > 18
