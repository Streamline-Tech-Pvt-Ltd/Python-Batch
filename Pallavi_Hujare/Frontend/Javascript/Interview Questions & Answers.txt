Answer:
JavaScript is a high-level, dynamically typed programming language used to make web pages interactive and dynamic.
Example:

11. What is the difference between var, let, and const?
| Feature                 | `var`          | `let`  | `const` |
| ----------------------- | -------------- | ------ | ------- |
| Reassign                | ✅ Yes        | ✅ Yes  | ❌ No  |
| Redeclare in same scope | ✅ Yes         | ❌ No   | ❌ No |
| Scope                   | Function       | Block  | Block   |
| Modern usage            | Less preferred | Common | Common  |

let age = 20;
age = 21;       // ✅

pi = 3.15;      // ❌ Error


12. Can we redeclare a let variable?
Answer:
No. A let variable cannot be redeclared in the same scope.
let age = 20;
let age = 21;   // ❌ Error

But it can be reassigned:
let age = 20;
age = 21;       // ✅


13. Can we reassign a const variable?
Answer:
No. A const variable cannot be reassigned after initialization.

const age = 20;
age = 21;       // ❌ Error

Important interview point:
const prevents reassignment of the binding. It does not make objects or arrays completely immutable.

14. What is scope?
Answer:
Scope defines where a variable can be accessed in a program.
Main types:
Global scope
Function scope
Block scope

Example:
let name = "Pallavi";

function test() {
    console.log(name);
}

Here name can be accessed inside the function because it is in an outer/global scope.

15. What is block scope?
Answer:
Block scope means a variable is accessible only inside the block { } where it is declared.
let and const are block-scoped.

if (true) {
    let age = 20;
    console.log(age); // ✅
}
console.log(age);    // ❌ Erro

16. What is function scope?
Answer:
Function scope means a variable declared with var inside a function can be accessed within that function, but not outside it.
function test() {
    var age = 20;
    console.log(age); // ✅
}

console.log(age);    // ❌

40. What is an if statement?
Expected answer:
The if statement is used to execute a block of code only when a specified condition is true.
let age = 20;
if (age >= 18) {
    console.log("Eligible to vote");
}
Interview point:
If the condition is false, the code inside if does not execute.

41. What is the difference between if, else, and else if?
Expected answer:
if checks the first condition, else if checks another condition when the previous condition is false, and else executes when none of the conditions are true.
let marks = 75;
if (marks >= 90) {
    console.log("A");
} else if (marks >= 60) {
    console.log("B");
} else {
    console.log("C");
}

Important: You can have multiple else if blocks, but only one starting if.

46. What is a switch statement?
Expected answer:
A switch statement is used to execute different blocks of code based on different possible values of an expression.
Example:
let day = 2;
switch (day) {
    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    case 3:
        console.log("Wednesday");
        break;

    default:
        console.log("Invalid day");
}

Important keywords:
| Keyword   | Purpose                   |
| --------- | ------------------------- |
| `switch`  | Starts switch statement   |
| `case`    | Defines possible value    |
| `break`   | Stops execution           |
| `default` | Runs when no case matches |


47. What is the difference between break and continue?

⭐ Very importan
Expected answer:
break completely terminates the loop, while continue skips the current iteration and moves to the next iteration.

break
for (let i = 1; i <= 5; i++) {
    if (i == 3) {
        break;
    }
    console.log(i);
}

Output:
1
2


continue
for (let i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    console.log(i);
}

Output:
1
2
4
5
Easy way to remember:
break → Stop the loop
continue → Skip current iteration

48. What is a for loop?

A for loop is used to repeatedly execute a block of code when the number of iterations is known or easily controlled.

}

Example:

1
2
3
4

Initialization → Condition → Increment/Decrement

49. What is a while loop?
Expected answer:
A while loop repeatedly executes code as long as the specified condition is true.
Syntax:
while (condition) {
    // code
}
Example:
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;
}

Output:
1
2
3
4
5

50. What is a do...while loop?
Expected answer:
A do...while loop executes the code block first and then checks the condition. Therefore, it executes at least once.
Example:
let i = 1;
do {
    console.log(i);
    i++;
} while (i <= 5);

Output:
1
2
3
4
5
Important interview question:

51: Which loop executes at least once?
Answer:
do...while loop.
Example:
let i = 10;
do {
    console.log(i);
} while (i < 5);

Output:
10


52. What is an infinite loop?
⭐ Important
Expected answer:
An infinite loop is a loop that never becomes false and therefore continues executing indefinitely.
Example:

let i = 1;
while (i <= 5) {
    console.log(i);
}

Here, i is never increased, so the condition always remains true.
Correct version:
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;
}

53. What is a nested loop?
Expected answer:
A nested loop is a loop inside another loop.
Example:
for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {
        console.log(i, j);
    }
}

The outer loop executes, and for each outer iteration, the inner loop executes completely.

Common uses:
Pattern programs
Matrix operations
Comparing elements
Working with 2D arrays

54. What is array traversal using loops?
Expected answer:
Array traversal means visiting or accessing each element of an array one by one using a loop.
Example:
let numbers = [10, 20, 30, 40];
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}

Output:
10
20
30
40
Using for...of
let numbers = [10, 20, 30, 40];
for (let number of numbers) {
    console.log(number);
}



55. Difference between for, while, and do...while
⭐ Extremely important interview question
Expected answer:
for is generally used when the number of iterations is known, while is used when the condition controls the repetition, and do...while is used when the code must execute at least once.

| Feature           | `for`               | `while`         | `do...while`      |
| ----------------- | ------------------- | --------------- | ----------------- |
| Condition checked | Before              | Before          | After             |
| Minimum execution | 0                   | 0               | **1**             |
| Best used when    | Iterations known    | Condition-based | Must execute once |
| Initialization    | Usually inside      | Usually before  | Usually before    |
| Increment         | Usually inside loop | Usually inside  | Usually inside    |

Example
for:
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
while:
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;
}

do...while:
let i = 1;
do {
    console.log(i);
    i++;
} while (i <= 5);


56. What is for...of?
Expected answer:
for...of is used to iterate over the values of an iterable such as an array or string.
let fruits = ["Apple", "Mango", "Banana"];
for (let fruit of fruits) {
    console.log(fruit);
}

Output:
Apple
Mango
Banana


57. What is for...in?
Expected answer:
for...in is mainly used to iterate over the enumerable property keys of an object.

let student = {
    name: "Pallavi",
    age: 21,
    marks: 85
};
for (let key in student) {
    console.log(key);
}

Output:
name
age
marks
