
 JAVASCRIPT?
JavaScript (JS) is a programming language used to make web pages interactive and dynamic.

Examples:
* Button clicks
* Form validation
* Pop-up messages
* Changing HTML and CSS
* Calculations
* Animations
* API calls

HTML + CSS + JavaScript:
HTML       -> Structure
CSS        -> Design
JavaScript -> Behavior / Logic

---------------------------------------------------------------------------------------------
| JavaScript                 | Java                              |
| -------------------------- | --------------------------------- |
| Dynamically typed          | Statically typed                  |
| Mainly web development     | Backend & enterprise applications |
| Runs in browser / Node.js  | Runs on JVM                       |
| `.js`                      | `.java`                           |
| Uses `let`, `const`, `var` | Uses explicit data types          |
| Example: `let age = 20;`   | Example: `int age = 20;`          |
---------------------------------------------------------------------------------------------------

 WHERE DOES JAVASCRIPT RUN?
JavaScript can run in:

2. Outside the browser

# JAVASCRIPT SYNTAX
JavaScript instructions are called statements.

Example:
let name = "Pallavi";
console.log(name);

Semicolon can be used at the end of a statement.

Example:
let age = 20;
let city = "Nashik";

********* VARIABLES **********
A variable is used to store data.


| Keyword   | Definition                                                   | Example            |
| --------- | ------------------------------------------------------------ | ------------------ |
| **var**   | Used to declare a variable; can be reassigned and redeclared | `var age = 20;`    |
| **let**   | Used to declare a variable whose value can be changed        | `let age = 20;`    |
| **const** | Used to declare a variable that cannot be reassigned         | `const pi = 3.14;` |
   

 1] let
let is used to declare a variable whose value can be changed.

Example:
let age = 20;
age = 21;

console.log(age);
Output:
21

2] const
const is used when a variable should not be reassigned.
Example:
const pi = 3.14;
console.log(pi);

This is not allowed:
const pi = 3.14;
pi = 4;
Simple rule:
let   -> value can change
const -> value cannot be reassigned

3] var
var is an older way of declaring variables.
Example:
var name = "Pallavi";

 #   Modern JavaScript generally prefers:
let
const
As a beginner, focus mainly on let and const.

*********RULES FOR VARIABLE NAMES*****&
Valid variable names:

let name = "Pallavi";
let age1 = 20;
let studentName = "Pallavi";

Invalid variable names:
let 1age = 20;
let student-name = "Pallavi";

Variable names should not start with a number.
Use camelCase for multiple words.

Example:
let studentName = "Pallavi";
let totalMarks = 90;
let phoneNumber = 1234567890;
---------------------------------------------------------------------------------------------
*********  Data Types  ********

| Data Type     | Definition                      | Example             |
| ------------- | ------------------------------- | ------------------- |
| **String**    | Stores text                     | `"Pallavi"`         |
| **Number**    | Stores numbers                  | `20`                |
| **BigInt**    | Stores very large integers      | `12345n`            |
| **Boolean**   | Stores true/false               | `true`              |
| **Undefined** | Declared but no value           | `let x;`            |
| **Null**      | Intentional empty value         | `let x = null`      |
| **Symbol**    | Creates unique values           | `Symbol("id")`      |
| **Object**    | Stores multiple key-value pairs | `{name: "Pallavi"}` |


----------------------------------------------------------------------------------------------
**  typeof Operator
Used to check the data type of a value.


** length Property
Used to find the number of characters in a String or number of elements in an Array.
Return type of length is Number.

Example:
let name = "Pallavi";

console.log(name.length);                       // 7
console.log(typeof name.length);                // number

----------------------------------------------------------------------------------------------

** Operators 

| Operator Type             | Definition                                        | Operators                 | Example                         |
| ------------------------- | ------------------------------------------------- | ------------------------- | ------------------------------- |
| **Arithmetic**            | Performs mathematical operations                  | `+ - * / % **`            | `10 + 5`                        |
| **Assignment**            | Assigns or updates a value                        | `= += -= *= /= %=`        | `x = 10`                        |
| **Comparison**            | Compares two values                               | `== === != !== > < >= <=` | `10 > 5`                        |
| **Logical**               | Combines or reverses conditions                   | `&& \|\| !`               | `age > 18 && age < 30`          |
| **Increment / Decrement** | Increases or decreases value by 1                 | `++ --`                   | `x++`                           |
| **Ternary**               | Short form of `if...else`                         | `? :`                     | `age >= 18 ? "Adult" : "Minor"` |
| **Type**                  | Checks or tests data types                        | `typeof`, `instanceof`    | `typeof age`                    |
| **Bitwise**               | Performs operations on binary bits                | `& \| ^ ~ << >> >>>`      | `5 & 1`                         |
| **Nullish coalescing**    | Uses fallback when value is `null` or `undefined` | `??`                      | `name ?? "Guest"`               |
| **Optional chaining**     | Safely accesses nested properties                 | `?.`                      | `user?.name`                    |
