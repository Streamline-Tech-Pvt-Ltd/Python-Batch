Q. What is Python?
A. Python is a simple,dynamic,high-level,interpreted,object oriented programming & general purpose programming language.

   Simple :-Python is considered simple because its syntax is easy to read and write, similar to English language statements.
   dynamic :-Python is a dynamically typed language, which means you do not need to declare the data type of a variable. Python automatically determines the type at runtime.
   high-level language :- programming language that is easy for humans to read, write, and understand. It uses English-like syntax and hides complex hardware details from the programmer.
   interpreted :- where code is executed line by line by an interpreter, instead of being compiled into machine code before execution.
   OOP :- organizes code using classes and objects. It helps make programs reusable, secure, and easy to maintain.


Q. Explain interpreter in details?
A. An interpreter is a software program that reads, translates, and executes code line by line.
   Python Interpreter executes your Python code and converts it into instructions that the computer can understand.

Q. Explain indentation  in pyhon?

   Indentation refers to the spaces or tabs at the beginning of a line of code. In Python, indentation is used to define code blocks and is mandatory.

Q. What is a variable in Python?

 Q.What are the rules for naming variables?
 A.# Rule 1: Variable name should start with A-Z, a-z, or _
name = "Pallavi"
print(name)

_name = "Pallavi"
print(_name)

# Rule 2: Variable names are case-sensitive
Name = "Pallavi"
name = "Hujare"

print(Name)  # Pallavi
print(name)  # Hujare

# Rule 3: Special characters are not allowed
# Invalid:
# @name = "Pallavi"
# print(@name)

# Rule 4: Spaces are not allowed
# Invalid:
# my name = "Pallavi"
# print(my name)

# Correct:
my_name = "Pallavi"
print(my_name)

# Rule 5: Variable name cannot start with a number
# Invalid:
# 1Name = "Pallavi"

# Correct:
name1 = "Pallavi"
print(name1)

# Rule 6: Keywords cannot be used as variable names
# Invalid:
# if = "Pallavi"
# print(if)

# Correct:
student_name = "Pallavi"
print(student_name)

Q. Difference between append() and extend()?
A: append() adds a single item, while extend() adds multiple items.
Example:
l1 = [1, 2]
l1.append(3)      # [1, 2, 3]
l2 = [1, 2]
l2.extend([3, 4]) # [1, 2, 3, 4]

Q. Difference between remove() and pop()?
A: remove() deletes an element by value, while pop() deletes an element by index.
Example:
l1 = [10, 20, 30]
l1.remove(20)  # Removes value 20
l1.pop(1)      # Removes element at index 1

Q. What is a Set in Python?
Answer:
A Set is an unordered collection of unique elements. It does not allow duplicate values and is defined using curly braces {}.
s = {10, 20, 30}


Q. What are the characteristics of a Set?
Answer:
Unordered
Mutable (can be modified)
Does not allow duplicate values
Does not support indexing or slicing

Q. Why are Sets used in Python?
Answer:
Sets are used to store unique values and perform mathematical operations such as union, intersection, and difference efficiently.


Q. What is the difference between a List and a Set?
List	Set
Ordered	Unordered

Q. What is the difference between remove() and discard() in a Set?
Answer:
remove() raises an error if the element is not present.
discard() does not raise an error if the element is not present.

Q. Can a Set contain mutable objects like Lists?
Answer:
No. Lists are mutable and cannot be stored inside a Set.
# Invalid

Q. What is the difference between add() and update()?
Answer:
add() adds a single element.
update() adds multiple elements.

Q. Why does a Set not support indexing?
Answer:
Because Sets are unordered collections and do not maintain element positions.

Q. What is a Frozen Set?
Answer:
A Frozen Set is an immutable version of a Set. Once created, it cannot be modified.
fs = frozenset([1, 2, 3])

Q. Explain Set operations in Python.
Answer:
Union (|) → Combines elements from both sets.
Intersection (&) → Common elements.
Difference (-) → Elements present in first set but not second.
Symmetric Difference (^) → Elements present in either set but not both.


Q. What is a Dictionary in Python?
Answer:
A Dictionary is a collection of data stored in key-value pairs.

student = {
    "name": "Pallavi",
    "age": 22
}

Q. What are the characteristics of a Dictionary?
Answer:
Stores data in key-value pairs
Mutable
Keys must be unique
Values can be duplicated
Fast data retrieval using keys

Q. What is the difference between a List and a Dictionary?
List                    	Dictionary
Access by index	     Access by key
Ordered collection	  Key-value pairs
Uses []	                 Uses {}

Q. Can Dictionary keys be duplicated?
Answer:
No. Keys must be unique. If duplicate keys are provided, the last value overwrites the previous one.

d = {"a": 1, "a": 2}
print(d)
# Output: {'a': 2}


Q. Can Dictionary values be duplicated?
Answer:
Yes. Multiple keys can have the same value.

d = {"a": 100, "b": 100}

Q. What is the difference between get() and direct key access?
Answer:
get() returns None if the key is not found.
Direct access raises a KeyError.

Q. What is the difference between pop() and del?
Answer:
pop() removes an item and returns its value.
del removes an item without returning a value.

Q. What do keys(), values(), and items() methods return?
Answer:
keys() → All keys
values() → All values
items() → All key-value pairs

Q. Can a Dictionary be nested?
Answer:
Yes. A Dictionary can contain another Dictionary.

student = {
    "name": "Pallavi",
    "marks": {
        "Python": 90,
        "Java": 85
    }
}


Q. Why are Dictionaries faster for searching data?
Answer:
Because Dictionaries use a hash table internally, allowing quick access to values using keys.
