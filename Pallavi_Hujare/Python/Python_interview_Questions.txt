Q. What is Python?
A. Python is a simple,dynamic,high-level,interpreted,object oriented programming & general purpose programming language.

   Simple :-Python is considered simple because its syntax is easy to read and write, similar to English language statements.
   dynamic :-Python is a dynamically typed language, which means you do not need to declare the data type of a variable. Python automatically determines the type at runtime.
   high-level language :- programming language that is easy for humans to read, write, and understand. It uses English-like syntax and hides complex hardware details from the programmer.
   interpreted :- where code is executed line by line by an interpreter, instead of being compiled into machine code before execution.
   OOP :- organizes code using classes and objects. It helps make programs reusable, secure, and easy to maintain.


Q. Explain interpreter in details?
A. An interpreter is a software program that reads, translates, and executes code line by line.
   Python Interpreter executes your Python code and converts it into instructions that the computer can understand.

Q. Explain indentation  in pyhon?
A. defines a block of code.
   Indentation refers to the spaces or tabs at the beginning of a line of code. In Python, indentation is used to define code blocks and is mandatory.
   Python typically uses 4 spaces for each indentation level. Incorrect indentation results in an IndentationError.

Q. What is a variable in Python?
A: A variable is a name used to store data in memory.
i.e:
name = "Pallavi"

 Q.What are the rules for naming variables?
 A.# Rule 1: Variable name should start with A-Z, a-z, or _
name = "Pallavi"
print(name)

_name = "Pallavi"
print(_name)

# Rule 2: Variable names are case-sensitive
Name = "Pallavi"
name = "Hujare"

print(Name)  # Pallavi
print(name)  # Hujare

# Rule 3: Special characters are not allowed
# Invalid:
# @name = "Pallavi"
# print(@name)

# Rule 4: Spaces are not allowed
# Invalid:
# my name = "Pallavi"
# print(my name)

# Correct:
my_name = "Pallavi"
print(my_name)

# Rule 5: Variable name cannot start with a number
# Invalid:
# 1Name = "Pallavi"

# Correct:
name1 = "Pallavi"
print(name1)

# Rule 6: Keywords cannot be used as variable names
# Invalid:
# if = "Pallavi"
# print(if)

# Correct:
student_name = "Pallavi"
print(student_name)

Q.What is an f-string?
A: An f-string is used to insert variables directly inside a string.
Example:
name = "Pallavi"
print(f"My name is {name}")
Output:
My name is Pallavi
