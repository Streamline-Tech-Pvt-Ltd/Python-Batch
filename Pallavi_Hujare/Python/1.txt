Why is a tuple faster than a list?
tuple is faster than a list because it is immutable. Since tuple elements cannot be added, removed,
or modified after creation, Python doesn't need to allocate extra memory for changes or perform modification operations.
This makes tuples more memory-efficient and slightly faster than lists.

here are four pillars of Object-Oriented Programming (OOP):

1. Encapsulation –
 Wrapping data (variables) and methods (functions) into a single unit (class). 
It also helps protect data using access modifiers like public, protected, and private.

2. Abstraction – 
Hiding the implementation details and showing only the essential functionality to the user.
 In Python, abstraction can be achieved using abstract classes from the abc module.

3. Inheritance – 
A child class acquires the properties and methods of a parent class, promoting code reusability.
 Python supports single, multiple, multilevel, hierarchical, and hybrid inheritance.

4. Polymorphism – The same method or interface can behave differently depending on the object.
 A common example is method overriding, where a child class provides its own implementation of a parent class method.

Method Overloading means having multiple methods with the same name but different parameters.
Python does not support method overloading in the traditional sense like Java or C++. However, 
similar behavior can be achieved using default arguments or *args.
Method Overriding means a child class provides its own implementation of a 
method that already exists in the parent class. Python fully supports method overriding.

 It is commonly used for tasks such as logging, authentication, authorization, timing, and caching.


Deep copy vs shallow copy
| Shallow Copy                 | Deep Copy                                          |
| ---------------------------- | -------------------------------------------------- |
| Copies only the outer object | Copies the entire object, including nested objects |
| Nested objects are shared    | Nested objects are copied independently            |
| Faster                       | Slightly slower                                    |
| Uses `copy.copy()`           | Uses `copy.deepcopy()`                             |

Easy Trick to Remember
Shallow Copy = Surface copy (shares nested objects)
Deep Copy = Complete copy (everything is copied)

map(), filter(), and reduce() are higher-order functions in Python.
map() applies a function to every element of an iterable and returns a new iterator.
filter() selects only those elements that satisfy a given condition.
reduce() repeatedly combines all elements into a single value. It is available in the functools module.


GIL (Global Interpreter Lock) is a mechanism in CPython that allows only one 
thread to execute Python bytecode at a time, even if multiple threads exist.
 Because of the GIL, Python threads cannot achieve true parallel execution for CPU-bound tasks.

 | Multithreading           | Multiprocessing          |
| ------------------------ | ------------------------ |
| Multiple threads         | Multiple processes       |
| Shared memory            | Separate memory          |
| Best for I/O-bound tasks | Best for CPU-bound tasks |
| Affected by GIL          | Not affected by GIL      |
