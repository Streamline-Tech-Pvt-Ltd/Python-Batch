*********Git Commands*********

###   This commands run on VS code 

1.git --version
  Purpose : used to Verify installation.

2.git clone <repository-url path>
  Purpose: Downloads an existing GitHub repository to the computer.

3.git status
  Purpose : Shows the current state of the Git repository.

4.git add .
Purpose: Adds all new, modified, and deleted files in the current folder and its subfolders to the staging area.

5.git commit -m "Message"
Purpose : Creates a commit (snapshot) of all files that have been added to the staging area.

6.git push origin main
Purpose :Uploads your local commits from the main branch to the GitHub repository.

****Git configuration is used to set your name and email so Git can identify who made each commit.****
 
 #### This commands run on Git Bash

1. git config --global user.name "Your Name"

Example
git config --global user.name "pallaviHujare123-cell"

Purpose
Sets your username for all Git repositories on computer.
Your name appears in commit history.


2. git config --global user.email "email"

Example
git config --global user.email "pallavihujare123@gmail.com"

Purpose :Sets email for Git commits.
Should ideally match GitHub email.


3.git config --list

Purpose :Displays all Git settings.

Example Output
user.name=pallaviHujare123-cell
user.email=pallavihujare123@gmail.com
