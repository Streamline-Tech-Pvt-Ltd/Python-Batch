========================================Joins==================================================

SQL JOINS is used to combine data from two or more tables based on a common column.

Types of SQL JOINs:-

1) INNER JOIN :- returns only matching records from both tables.

SELECT * 
FROM A
INNER JOIN B
ON A.id = B.id;

2) LEFT JOIN :- return all records from left table + matching from right.

SELECT * 
FROM A
LEFT JOIN B
ON A.id = B.id;

3) RIGHT JOIN :- return all records from right table + matching from left.

SELECT * 
FROM A
RIGHT JOIN B
ON A.id = B.id;

4) FULL JOIN :- returns all records from both tables (matched + unmatched)

SELECT * 
FROM A
FULL JOIN B
ON A.id = B.id;
