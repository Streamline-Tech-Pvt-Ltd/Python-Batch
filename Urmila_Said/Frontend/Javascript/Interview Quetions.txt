5. What is a variable?
Ans: A variable is a container used to store data.
let age = 22;
let name = "Urmila";

6. What are var, let and const?
Ans: They are used to declare variables.
var x = 10;
let y = 20;
const z = 30;

Simple difference:
| Keyword | Reassign? | Scope    |
| ------- | --------- | -------- |
| `var`   | Yes       | Function |
| `let`   | Yes       | Block    |
| `const` | No        | Block    |

9. What is an Array?
Ans : An array stores multiple values in one variable.
Ex: let fruits = ["Apple", "Mango", "Banana"];

10. What is an Object?
Ans: An object stores data in key-value pairs.
let student = {
    name: "Urmila",
    age: 22,
    marks: 85
};

11. What are operators?

console.log(a + b);

Types:
Arithmetic
