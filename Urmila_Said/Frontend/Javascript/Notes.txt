# Conditional Statement: 
A conditional statement is used to make a decision in JavaScript.

It checks a condition:
If the condition is true → one block of code runs.
If the condition is false → another block can run.

* Types of Conditional Statements

| Statement             | Use                                  |
| --------------------- | ------------------------------------ |
| `if`                  | Executes code when condition is true |
| `if...else`           | Chooses between two conditions       |
| `if...else if...else` | Checks multiple conditions           |
| `switch`              | Selects one option from many         |
| Ternary `?:`          | Short form of `if...else`            |


1. if Statement
Used when you want to execute code only when a condition is true.
Syntax: if (condition) {
    // code
}

EX: let age = 20;
if (age >= 18) {
    console.log("Adult");
}

2. if...else Statement
Used when there are two possibilities.
Syntax: if (condition) {
    // if condition is true
} else {
    // if condition is false
}

EX: let age = 16;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

3. if...else if...else
Used when you have multiple conditions.

EX: let marks = 75;

if (marks >= 90) {
    console.log("Grade A+");
} else if (marks >= 75) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else {
    console.log("Fail");
}

4. Ternary Operator
The ternary operator is a short way to write if...else.

Ex: let age = 20;
let result = age >= 18 ? "Adult" : "Minor";
console.log(result);

# Loops:
A loop in JavaScript is used to execute the same block of code repeatedly until a particular condition becomes false.

1. for Loop
The for loop is used when we know how many times we want to execute the code.

* Syntax :
 for (initialization; condition; increment/decrement) {
    // code
}

* Ex: Print 1 to 10
for (let i = 1; i <= 10; i++) {
    console.log(i);
}

* How it works
let i = 1       → Initialization
i <= 10         → Condition
console.log(i)  → Code execution
i++             → Increment

2. while Loop
The while loop executes the code as long as the condition is true.

* Syntax :
while (condition) {
    // code
}

* Ex: 
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

3. do...while Loop
The do...while loop executes the code at least once, even if the condition is false.

* Syntax
do {
    // code
} while (condition);

* EX: 
let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);


# Important Difference

> while checks the condition before execution.
> do...while checks the condition after execution.


# Loop Comparison

| Loop         | Condition Check  | Best Used For                   |
| ------------ | ---------------- | ------------------------------- |
| `for`        | Before execution | Known number of repetitions     |
| `while`      | Before execution | Condition-based repetition      |
| `do...while` | After execution  | Code must execute at least once |

# The Break Statement
The break statement "jumps out" of loops and switches.
The break statement terminates the execution of a loop or a switch statement.
No more loop iterations are executed.
for (let i = 0; i < 10; i++) {
  if (i === 3) { 
break; 
}
  text = "The number is " + i + "\n";
}

# Break in a Switch statement:
In a switch statement, a break statement will exit the switch block after a matching case is executed.
Ex-
let dayNumber = 3;
let dayName;
switch (dayNumber) {
  case 0:
    dayName = "Sunday";
    break;
  case 1:
    dayName = "Monday";
    break;
  case 2:
    dayName = "Tuesday";
    break;
  case 3:
    dayName = "Wednesday";
    break;
  case 4:
    dayName = "Thursday";
    break;
  case 5:
    dayName = "Friday";
    break;
  case 6:
    dayName = "Saturday";
    break;
  default:
    dayName = "Invalid day";
}
console.log(dayName);


# The Continue Statement
The continue statement skips the current iteration in a loop.
The remaining code in the iteration is skipped and processing moves to the next iteration.
Ex-
for (let i = 1; i < 10; i++) {
  if (i === 3) { 
continue; 
}
  text += "The number is " + i + "\n";
}

# Why do we use DOM?
JavaScript uses the DOM to perform many operations on a webpage.

Ex: document.getElementById("demo").style.color = "red";

5. Add HTML elements
Ex: const p = document.createElement("p");

6. Remove HTML elements
Ex: element.remove();

7. Handle events
Ex: button.addEventListener("click", function() {

8. Create dynamic web pages
Ex : User clicks button
        ↓
JavaScript executes
        ↓
DOM changes
        ↓
Page content changes

8. Changing an element using querySelectorAll() 
Ex: const myItems = document.querySelectorAll(".demo");
myItems[0].innerHTML = "First";

9. Changing ALL elements with querySelectorAll(): If you want to change all matching elements, use a loop.
Ex: const items = document.querySelectorAll(".demo");
items.forEach(function(item) {
    item.innerHTML = "Hello";
});


#  querySelector() vs querySelectorAll()
| `querySelector()`              | `querySelectorAll()`          |
| ------------------------------ | ----------------------------- |
| Returns first matching element | Returns all matching elements |
| One element                    | Multiple elements             |
| Uses CSS selector              | Uses CSS selector             |
| No indexing normally required  | Can use indexing              |
| `querySelector(".demo")`       | `querySelectorAll(".demo")`   |


# All DOM Selection Methods — Quick Chart
| Method                     | Selects by   | Result                 |
| -------------------------- | ------------ | ---------------------- |
| `getElementById()`         | ID           | Single element         |
| `getElementsByTagName()`   | Tag          | Collection             |
| `getElementsByClassName()` | Class        | Collection             |
| `querySelector()`          | CSS selector | First matching element |
| `querySelectorAll()`       | CSS selector | All matching elements  |
