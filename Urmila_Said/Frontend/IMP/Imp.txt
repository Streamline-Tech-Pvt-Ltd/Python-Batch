# HTML5

1.What is HTML, and what does HTML5 add?
Ans: HTML (HyperText Markup Language) structures web content. HTML5 added semantic elements, 
native audio and video, richer form controls, and browser APIs.

2.What is the purpose of <!DOCTYPE html>?
Ans: tells the browser to use modern standards mode for consistent rendering.

3. What are semantic elements? Name a few and explain when you would use them.
Ans: Semantic elements describe their purpose: header for introductory content, nav for
 navigation, main for primary content, and footer for closing information.

4. What is the difference between <div> and <span>?
Ans: div is a generic block container; span is a generic inline container. Prefer a semantic 
element when one describes the content.

5. How are block-level and inline elements different?
Ans: Block elements normally begin on a new line and take available width; inline elements
 flow within text and take the space they need.

6.When should you use <section>, <article>, <nav>, and <aside>?
Ans:section groups a themed topic; article is self-contained content; nav holds major 
navigation; aside holds complementary related content

7.What are HTML attributes? How are id and class different?
Ans: Attributes add information or behavior. An id should uniquely identify one
 element; a class can be shared by many elements

8.How do you connect a label to an input field, and why is it useful?
Ans: Match the label's for value to the input's id, for example label for=email and input id=email.
 This improves the click target and accessible name.

9.What are the purposes of the alt, required, and placeholder attributes?
Ans: alt provides an image text alternative; required makes a field mandatory; placeholder
 gives a hint but should not replace a label.

10.How do you add audio or video to a page with HTML?
Ans: Use audio or video with controls and a source element specifying its URL and media type. 
Provide captions for video when needed.

11.What is the difference between localStorage, sessionStorage, and cookies?
Ans: localStorage persists until cleared; sessionStorage lasts for the tab session; cookies can
 expire and are sent with matching HTTP requests

12.How do you make a form use built-in browser validation?
Ans: Use input types and constraints such as type=email, required, minlength, and min. The browser validates them on submission.

# CSS

1.What is CSS, and what are the three ways to apply it to a page?
Ans: CSS styles presentation. Apply it inline, in a style block, or in an external stylesheet linked
 with link.

2. Explain the CSS box model. What do content, padding, border, and margin mean?
Ans: The box model is content, padding, border, and outside margin. With box-sizing:border-box, 
declared dimensions include padding and border.

3. What is the difference between a class selector and an ID selector?
Ans: A class is reusable across elements and selected with .name. An id is intended to be 
unique and selected with #name.

4.What is CSS specificity, and how does the browser decide which rule wins?
Ans: Specificity ranks matching rules: IDs generally outrank classes and attributes, which outrank
 element selectors. Ties are resolved by later rules; cascade origin and !important also matter.

5.What is the difference between display: none, visibility: hidden, and opacity: 0?
Ans: display:none removes layout space; visibility:hidden hides the item but keeps its space; 
opacity:0 makes it transparent while it may still receive interaction.

6.How do position: relative, absolute, fixed, and sticky differ?
Ans: relative offsets from normal position; absolute positions against a containing block; 
fixed is viewport-relative; sticky scrolls until it sticks within its scroll container.

7.What are Flexbox and CSS Grid? When might you choose each?
Ans: Flexbox is suited to a one-dimensional row or column; Grid arranges rows and columns together.
Choose by the layout needs, and combine them if useful.

8. What is the difference between a CSS pseudo-class and a pseudo-element?
Ans: A pseudo-class selects a state, such as :hover. A pseudo-element styles a part or generated content,
 such as ::before.

9. What are media queries, and how do they help build responsive pages?
Ans: Media queries apply styles when conditions such as viewport width match, helping layouts adapt 
to screen sizes and capabilities.

10. What is the difference between px, %, em, and rem?
Ans: px is a CSS pixel; % is relative to a containing value; em relates to font size (depending on the
 property); rem relates to the root font size

11.How can you center an element horizontally and vertically?
Ans: For example, use display:flex with align-items:center and justify-content:center. 
Grid place-items:center is another option.

12. What is the difference between margin and padding?
Ans: Margin is outside an element's border. Padding is between its content and border.

# JAVASCRIPT

1.What is JavaScript used for in a frontend application?
Ans: JavaScript adds interactivity: responding to events, changing the DOM, validating input, and
 requesting data from services.

2.How do var, let, and const differ?
Ans: var is function-scoped and can be redeclared; let is block-scoped and reassigned; const is
 block-scoped and cannot be reassigned. Prefer const unless reassignment is needed.

3.What are JavaScript data types? What is the difference between a primitive value and an object?
Ans: Primitive types include string, number, bigint, boolean, undefined, symbol, and null. Objects 
(including arrays and functions) group properties; primitive values are immutable.

4.What is the difference between == and ===?
Ans: == may convert types before comparing; === compares without that conversion, so it checks
 both type and value. Strict equality is usually clearer.

5. What are functions, and how is an arrow function written?
Ans: A function is reusable code that can accept inputs and return a value. Arrow example: const
 add = (a,b) => a + b.

6.What is scope? Explain global scope, function scope, and block scope.
Ans: Scope determines where a name is available: globally, within a function, or within a block. 
let and const are block-scoped.

7.What are arrays and objects? How do you read and update their values?
Ans: Arrays are ordered collections accessed by index, such as items[0]. Objects store named properties, 
such as user.name. Assign to either property to update it.

8.What do map(), filter(), and forEach() do?
Ans: map returns a transformed array; filter returns elements matching a condition; forEach runs 
a callback for each element and does not create a mapped array.

9.What is the DOM, and how can JavaScript select and update an element?
Ans: The DOM is the browser's object representation of a document. Select with document.querySelector 
and update textContent, attributes, or classes.

10.What is an event listener? Give an example of handling a button click.
Ans: An event listener runs a function for an event: button.addEventListener('click', handler).

11.What are event bubbling and event delegation?
Ans: Bubbling travels from the event target up through ancestors. Delegation uses an ancestor 
listener to handle matching descendant events.

12.What is the difference between null and undefined?
Ans: undefined often means a value was not assigned or is missing; null is an explicit absence of a value.

13.What are promises, and what do async and await do?
Ans: A promise represents an asynchronous result that fulfills or rejects. async functions return 
promises; await waits inside one, and try/catch handles errors.

14.How do you handle an error in JavaScript?
Ans: Use try/catch for exceptions and promise failures, validate inputs, and show a useful recovery 
message instead of silently ignoring errors.

15.What do JSON.stringify() and JSON.parse() do?
Ans: JSON.stringify converts a JSON-compatible value to a JSON string; JSON.parse converts a JSON 
string back to a JavaScript value.
