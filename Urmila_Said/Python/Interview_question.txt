# Interview Questions & Answer

1. What is python ?
Ans:.Python is a simple,high level,dynamic,interpreted and general purpose programming language.
     1)Simple:Python is easy to learn and write.
     2)High level:Python uses human-readable words, so programmers don't need
       to manage complex computer hardware details.
     3)Dynamic:You don't need to specify the data type of a variable. 
     4)Interpreted:Python executes code line by line instead of converting
       the entire program into machine code before running.
     5)General purpose:Python can be used for many different types of applications.

2. Explain interpreted in detail ?
Ans:.Python is an interpreted language because its source code is executed line by line
     by the Python interpreter without requiring separate compilation.This makes debugging 
     easier and program development faster.

3. Explain indentation in python ?
Ans:.Indentation is the use of spaces or tabs at the beginning of a line to define a 
     block of code in Python.It is mandatory and helps improve code readability and structure.

4. Difference between static & dynamic ?
Ans:.| Static                                                   |             Dynamic                                 
| ------------------------------------------------------------- | --------------------------------------------------- |
| Variable type is declared before use.                         | Variable type is decided automatically at runtime.  |
| Data type cannot change easily.                               | Data type can change during execution.              |
| Errors related to types are found beforerunning the program.  | Type errors are found while the program is running. |
| More strict.                                                  | More flexible.                                      |
| Examples: C, C++, Java                                        | Examples: Python, JavaScript                        |

5. What is IDE & Give me three example ?
Ans:.IDE (Integrated Development Environment) is software that provides tools such as a code editor,
     compiler/interpreter, and debugger in a single environment for developing programs.
      Examples;PyCharm, Visual Studio Code,Jupyter notebook and Spyder.

6. Explain the types of python language ?
Ans:.1. Sequential Programming
        In sequential programming, statements are executed one after another in order 
        from top to bottom.
     2. Functional Programming
        In functional programming the program is divided into functions. Each function performs 
        a specific task and can be called whenever needed.
     3. Object-Oriented Programming (OOP)
        In OOP programs are organized using classes and objects Data and functions
         are combined into a single unit called an object.

 8. What are the rules for naming variables ?
 Ans:. Rule 1:Variable name must start with a letter (A-Z, a-z) or underscore (_)
     EX: name = "Urmila"
         print(name)

         _name="Urmila"
         print(_name)

   * Rule 2:Variable name cannot start with a number
      Ex: Invalid
      2Name = "Urmila" 

     #Valid
     name2 = "Urmila"
     print(name2)

  * Rule 3:Special characters are not allowed
      Ex: Invalid     
         student@name = "Urmila"
      
  * Rule 4:Variable names are case-sensitive
     name = "Urmila"
     Name = "Said"
     print(Name) # Said
     print(name) # Urmila

  * Rule 5:Spaces are not allowed
     Ex:Invalid
      my name = "Urmila"
      print(my name)

    # Correct
     my_name = "Urmila"
     print(my_name)

 * Rule 6:Keywords cannot be used as variable names
     Ex:Invalid
      if = "Urmila"
      print(if)

   # Correct
    student_name = "Urmila" 
    print(student_name)

9. What is a naming convention in Python?
Ans:. Naming conventions are rules for writing variable, function, class, and constant names in a readable format.
    * Naming Conventions Four Cases

   1.snake_case (recommended variables & function)
   All letters are lowercase & Words are separated by underscores (_).
   student_name = "Urmila"

   2.camelCase 
   First word starts with a lowercase letter & Next word start with uppercase letter. 
   studentName = "Urmila"

    3.PascalCase (use for classes)
    Every word starts with a capital letter.
    class StudentDetails:

   4.UPPER_CASE (used for constants)
    All letters are capital & Words are separated by underscores.
    MAX_SIZE = 100

29.What is indexing in python ?
Ans:Indexing is used to access individual elements (characters or items) from a sequence
    such as a string, list, tuple, etc., using their position number called an index.

    * Positive Indexing: Positive indexing starts from 0 and moves from left to right.
      Ex:name = "Python"
        print(name[0])  # P
        print(name[1])  # y
        print(name[2])  # t

    * Negative Indexing: Negative indexing starts from -1 and moves from right to left.
      Ex:name = "Python"
         print(name[-1])  # n
         print(name[-2])  # o
         print(name[-3])  # h

30.What is slicing in Python ?
Ans:Slicing is used to access a range of multiple elements from a string, list, or tuple.
    * sequence[start : stop : step]

    start → Starting index (included)
    stop → Ending index (Index it will stop before that number)
    step → Increment/decrement value (Number of position to move)
    Ex:numbers = [10, 20, 30, 40, 50]
       print(numbers[1:4])

31.What is the difference between indexing and slicing ?
Ans:
| Indexing                                  | Slicing                                         |
| ----------------------------------------- | ----------------------------------------------- |
| Used to access **one element** at a time. | Used to access **multiple elements** (a range). |
| Returns a single value.                   | Returns a sequence (string, list, tuple, etc.). |
| Uses one index position.                  | Uses start, stop, and step values.              |
| Syntax: `sequence[index]`                 | Syntax: `sequence[start:stop:step]`             |

32.What does [::-1] do in Python ?
Ans:reverses a sequence (string, list, or tuple) by traversing it from the end to the beginning using a step value of -1.

33.Difference between append() and extend() ?
Ans:
| Feature     |  append()                                  |  extend()                                     |
| ----------- | ------------------------------------------ | --------------------------------------------- |
| Purpose     | Adds a single element at the end of a list | Adds multiple elements from another iterable  |
| Argument    | Takes one item                             | Takes an iterable (list, tuple, string, etc.) |
| List Length | Increases by 1                             | Increases by the number of elements added     |
| Output      | Element is added as a single item          | Elements are added individually               |

33.Difference between remove() and POP() ?
Ans:
| Feature          |  remove()                                 |  pop()`                                       |
| ---------------- | ----------------------------------------- | --------------------------------------------- |
| Removes by       | **Value**                                 | **Index**                                     |
| Return Value     | Does not return the removed item (`None`) | Returns the removed item                      |
| Syntax           | `list.remove(value)`                      | `list.pop(index)`                             |
| Default Behavior | Must specify the value                    | Removes the last element if no index is given |
| Error            | `ValueError` if value not found           | `IndexError` if index is out of range         |
