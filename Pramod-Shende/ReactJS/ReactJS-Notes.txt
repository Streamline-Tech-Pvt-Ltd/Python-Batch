components: A Component is a reusable and independent piece of UI (User Interface) in React.

Components help divide a large application into smaller, manageable, and reusable parts.

Advantages of Components:

Reusability
Easy Maintenance
Better Code Organization
Improved Readability
Faster Development


2. Types of Components

React provides two types of components:

1. Functional Components
2. Class Components

1. Functional Component

A Functional Component is a JavaScript function that returns JSX.

Syntax

function Welcome() {
  return (
    <h1>Welcome to React</h1>
  );
}

export default Welcome;

2.Class Component

A Class Component is an ES6 class that extends React.Component and contains a render() method.

Syntax

import React, { Component } from 'react';

class Welcome extends Component {
  render() {
    return (
      <h1>Welcome to React</h1>
    );
  }
}

export default Welcome;


# Rules for Creating Components
Rule 1: Component Name Must Start with a Capital Letter


function Header() {
  return <h1>Header</h1>;
}

Rule 2: A Component Must Return JSX
function Header() {
  return (
    <h1>Welcome</h1>
  );
}

What is JSX?

JSX stands for JavaScript XML.

JSX allows us to write HTML-like code inside JavaScript.

Example
const element = <h1>Hello React</h1>;

Why JSX?

Without JSX:

React.createElement(
  'h1',
  null,
  'Hello React'
);

With JSX:

<h1>Hello React</h1>

JSX is easier to read and write.


JSX Rules

Rule 1: Single Parent Element

return (
  <div>
    <h1>Hello</h1>
    <p>React</p>
  </div>
);

Rule 2: Use className Instead of class

HTML:

<h1 class="title">Hello</h1>

JSX:

<h1 className="title">Hello</h1>


Rule 3: Close All Tags


<img src="logo.png" />


React Fragment

React Fragment allows grouping multiple elements without adding extra HTML elements.

Syntax
<>
  <h1>Hello</h1>
  <p>Welcome</p>
</>

1.JavaScript Expressions in JSX

JavaScript expressions can be written inside curly braces {}.

Example
function App() {

  return (

  );
}

2.Performing Calculations in JSX
function App() {

  const num1 = 10;
  const num2 = 20;

  return (

# React Conditional Rendering :
1. Using if...else:
Use if...else when you want to return completely different JSX.

ex. 

function App() {
  const isLogin = false;

  if (isLogin) {
    return <h1>Welcome User</h1>;
  } else {
    return <h1>Please Login</h1>;
  }
}

export default App;

2. Using Ternary Operator (? :) :

Syntax:-
          condition ? truePart : falsePart

Example 1:

function App() {
  const age = 22;

  return (
    <>
      {age > 20 ? (
        <h1>Eligible for Voting</h1>
      ) : (
        <h1>Not Eligible</h1>
      )}
    </>
  );
}

export default App;


Example 2: Login System using use state :-

import { useState } from "react";

function App() {
  const [login, setLogin] = useState(false);

  return (
    <>
      {login ? <h1>Welcome Page</h1> : <h1>Please Login</h1>}

      <button onClick={() => setLogin(!login)}>
        Login / Logout
      </button>
    </>
  );
}

export default App;

3. Logical AND (&&):

Displays JSX only when the condition is true.

Syntax:-
        condition && JSX code 

Ex.
function App() {
  const isAdmin = true;

  return (
    <>
      {isAdmin && <h1>Welcome Admin</h1>}
    </>
  );
}

export default App;

*Note:-
1.If isAdmin is false, nothing is displayed.

# map() Method in React:
map() is a JavaScript array method used to display multiple elements.

Syntax:-

array.map((item, index) => {
  return JSX;
});

Ex.
function App() {
  const students = ["Omkar", "Pramod", "Rushi", "Yash", "Urmila"];

  return (
    <>
      {students.map((student) => (
        <h1>{student}</h1>
      ))}
    </>
  );
}

export default App;

Output:-
Omkar
Pramod
Rushi
Yash
Urmila

Note: Always provide a key prop when using map() in React to help React efficiently update the UI.

{students.map((student, index) => (
  <h1 key={index}>{student}</h1>
))}


Summary:-
Method	                  Use
1.if...else	          Return completely different JSX
2.? : (Ternary)	      Display one of two JSX elements
3.&&	                Display JSX only if the condition is true
4.map()	              Display a list of elements from an array

These are the four most commonly used techniques for rendering content dynamically in React.
