*Higher Order Functions in Python:-
A Higher Order Function is a function that Takes another function as an argument, or Returns a function as output.
 
 ex.

1. filter():-
filter() is used to select elements from a list based on a condition. filter() returns only those elements that satisfy the condition.


ex.
    marks = [35,45,47,68,75,85,95]

    def fail_students(score):
        return score > 70
        result = filter(fail_students, marks)
    print(list(result))

Output:[75, 85, 95]


2. map():
map() is used to apply a function to every element of a list.

ex.
marks = [35,45,47,68,75,85,89,95,92]

def grade(marks):
    if marks > 90:
        return "Grade A"
    elif marks > 80:
        return "Grade B"
    elif marks > 70:
        return "Grade C"
    else:
        return "Fail Students"

grd = map(grade, marks)
print(list(grd))

Output:['Fail Students', 'Fail Students', 'Fail Students', 'Fail Students', 'Grade C', 'Grade B', 'Grade B', 'Grade A', 'Grade A']

3. reduce():
reduce() is used to apply a function cumulatively to all elements of a list and return a single value.
It is available in the functools module.

ex.
from functools import reduce
from operator import add

marks = [35,45,47,68,75,85,89,95,92]

result = reduce(add, marks)
print(result)

Output: 631 #reduce() performs addition step by step

*Difference Between filter(), map(), and reduce():-

1.filter():     Select elements based on condition	Filtered list.
2.map():	    Apply function to every element	Modified list.
3.reduce():     Combine all elements into single value	Single result.

*Inheritance :-

Inheritance is a feature of Object-Oriented Programming (OOP) where one class (child) gets properties and methods from another class (parent).

Parent Class (Base Class) → Gives properties
Child Class (Derived Class) → Uses those properties

 Benefit: Code reuse, less duplication, better structure

 1. Single Inheritance
 One child class inherits from one parent class.

ex.
	class Parent:
   	 name = "rahul"
    
    def property(self):
        return "parent property"

class Child(Parent):
    def education(self):
        return "education pursuing"

	obj = Child()
	print(obj.education())
	print(obj.property())
	print(obj.name)

Key Point: Child can access both its own and parent’s data.

 2. Multiple Inheritance
 One child class inherits from more than one parent class.

ex.
	class Father:
  	  def property(self):
              return "Father property"

	class Mother:
  	  def property1(self):
  	      return "mother property"

	class Child(Father, Mother):
   	 def education(self):
  	      return "education pursuing"

		obj = Child()
	print(obj.property())
	print(obj.property1())

 Key Point: Child gets features from multiple classes.

 3. Multilevel Inheritance
 Inheritance chain (Grandparent → Parent → Child)

ex.
	class GrandFather:
   	 name = "rahul"
    
  	  def property(self):
      	  return "GrandFather property"

	class Father(GrandFather):
  	  def property1(self):
  	      return "Father property"

	class Child(Father):
	    def education(self):
  	      return "education pursuing"

	obj = Child()
	print(obj.name)

 Key Point: Child can access all levels.

 4. Hierarchical Inheritance
 One parent → Multiple child classes

ex.
 class Father:
    def property(self):
        return "Father property"

class Son1(Father):
    def education1(self):
        return "Son1 property"

class Son2(Father):
    def education2(self):
        return "Son2 property"

obj1 = Son1()
print(obj1.education1())

 Key Point: Same parent shared by multiple children.

 5. Hybrid Inheritance
 Combination of multiple types of inheritance.

ex.

class Family:
    def member(self):
        return "family member"

class Father(Family):
    def dad(self):
        return "DAD"

class Son1(Father):
    def boy1(self):
        return "BOY 1"

class Son2(Father, Family):
    def boy2(self):
        return "BOY 2"

obj = Son2()
print(obj.boy2())

obj1 = Son1()
print(obj1.boy1())
print(obj1.dad())
print(obj1.member())

print(Son2.mro())

*MRO (Method Resolution Order):-
 Defines the order in which Python searches for methods in inheritance.

 print(Son2.mro())

 Output example:
	[Son2, Father, Family, object]

* Decorator:-
 A decorator is a function that wraps another function to extend or modify its behavior without changing its actual code.
 It is denoted by @ symbol.

ex.
def my_decorator(func):
    def wrapper():
        print("Something is happening before the function is called.")
        func()
        print("Something is happening after the function is called.")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()

* Encapsulation :-
Encapsulation = Data Binding + Data Hiding
It means:
Wrapping data (variables) and methods (functions) into a single unit (class)
Restricting direct access to some data.

it use private variables (__) to hide data and Use getter/setter to control access.
It Improves security and control.


Q. What is Encapsulation?
=> Protects data from unwanted changes, Improves security and Makes code more controlled and maintainable.

* Access Specifiers in Python:-

    Type	             Syntax	           Access Level

    1.Public	          name	           Accessible everywhere
    2.Protected	         _name	           Accessible but should be used carefully
    3.Private	         __name	           Not directly accessible outside class


ex.
class Employee:
    def __init__(self,name,role,salary,age):
        self.name = name        # public
        self._role = role       # protected
        self.__salary = salary  # private
        self.age = age          # public

*Getter and Setter :-
 1.Getter Method:
    Used to read private data

ex.

def get_salary(self):
    return self.__salary

2.Setter Method:
Used to update private data with conditions

def set_salary(self, sal):
    if sal >= 50000:
        self.__salary = sal
    else:
        print("Invalid salary")

obj = Employee("pramod","Full stack python developer",50000,21)
print("Original salary:", obj.get_salary())
obj.set_salary(40000)
print("Updated salary:", obj.get_salary())

Output:
Original salary: 50000
Invalid salary
Updated salary: 50000

Q. Why __salary is not directly accessible?
=> (__salary) is not directly accessible because it is declared as a private variable using double underscore (__).
    In Python, private variables are name-mangled to protect them from direct access outside the class.

* Polymorphism :-
Polymorphism = One name, many forms.
It means the same function/method behaves differently depending on the situation.

Python supports polymorphism mainly through overriding
Overloading is achieved using:
Default arguments : *args
Overriding requires inheritance
it Helps in code reusability and flexibility

# Types of Polymorphism:-

1) Compile-Time Polymorphism (Method Overloading):-
    Same method name with different parameters and it Decided at compile time.
    Python does NOT support method overloading

# How we achieve it in Python?
=> Using Default Arguments

ex.
def add(a, b, c=0):
    return a + b + c
print(add(2, 3))       # Output: 5
print(add(2, 3, 10))   # Output: 15

2) Run-Time Polymorphism (Method Overriding):-
    Same method name in parent and child class Child class changes the behavior and it Decided at runtime
    Fully supported in Python
    
    ex.

class Person:
    def age(self):
        print("this is the age of person")

class Student(Person):
    def age(self):
        return "this is the age of Student"

class Leader(Person):
    def age(self):
        return "this is the age of leader"

class Employee(Person):
    def age(self):
        return "this is the age of employee"

class Hr(Person):
    def age(self):
        return "this is the age of HR"


obj1 = Student()
print(obj1.age())

obj2 = Leader()
print(obj2.age())

obj3 = Employee()
print(obj3.age())

obj4 = Hr()
print(obj4.age())

 Output:-
this is the age of Student
this is the age of leader
this is the age of employee
this is the age of HR

* Explanation :-
All classes inherit from Person
Each class overrides the age() method
Same method name → different outputs → polymorphism

* Difference between overriding and overloading:-

Parameter	         Method Overloading	              Method Overriding
    
Method Name :        	    Same	                            Same
Parameters   :       	    Different	                        Same
Inheritance	  :             Not required	                    Required
Time           :     	    Compile Time	                    Runtime
Python Support	:           Not directly supported	            Supported
Concept Type	 :          Functional Programming style	    OOP concepts
